# Atividades Alura – Java (Encapsulamento)

Este repositório contém atividades práticas desenvolvidas durante meus estudos de **Java na Alura**, com foco em **classes, métodos, atributos e encapsulamento**.

O objetivo é praticar a modelagem de classes, organização do código e aplicação de conceitos básicos de Programação Orientada a Objetos.

---

## ✅ O que foi colocado em prática

Durante este curso, pratiquei conceitos fundamentais de Java, com foco em **encapsulamento**, incluindo:

- Criação e manipulação de classes para representar entidades do mundo real
- Organização de dados e comportamentos de forma estruturada
- Implementação de métodos que encapsulam lógicas específicas
- Controle de acesso aos atributos utilizando `private`
- Uso de métodos getters e setters para garantir a integridade dos dados
- Aplicação de boas práticas de Programação Orientada a Objetos
